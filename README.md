# ESports School League

Offizielle Demo-Plattform der ESports School League für Schülerinnen und Schüler.

## Tech Stack

- **React 19** + **TypeScript**
- **Vite** — Build-Tool
- **Tailwind CSS v4** — Styling
- **React Router v7** — Routing
- **Motion** — Animationen
- **localStorage** — Demo-Datenpersistenz

## Lokal starten

**Voraussetzungen:** Node.js 18+

```bash
npm install
npm run dev
```

Wenn das Projekt heruntergeladen wurde, läuft die Seite über [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

## Hinweis

Dies ist eine Demo-Anwendung. Alle Daten werden nur lokal im Browser-Cache gespeichert und sind nicht persistent über Geräte hinweg.
