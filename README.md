# ESports School League

DEMO des Schulprojekts zur fiktiven ESports School League.

## Tech Stack

- **React 19** + **TypeScript**
- **Vite** — Build-Tool
- **Tailwind CSS v4** — Styling
- **React Router v7** — Routing
- **Motion** — Animationen
- **localStorage** — Statt Datenbank

## Lokal starten

**Voraussetzungen:** Node.js 18+

```bash
npm install
npm run dev
```

Wenn das Projekt heruntergeladen wurde und npm installiert und gestartet wurde läuft die Seite über [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

## Hinweis

Dies ist eine Demo-Anwendung. Alle Daten werden nur lokal im Browser-Cache gespeichert und sind nicht persistent über Geräte hinweg.
